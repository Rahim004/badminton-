# Волан на игровых порталах

Игра готова к выкладке на три площадки: **itch.io**, **Яндекс Игры**, **CrazyGames**. Загружаете вы сами, здесь — всё, что для этого нужно: сборки, пошаговые руководства, тексты и картинки.

| Площадка | Архив | Руководство | Тексты | Картинки |
|---|---|---|---|---|
| itch.io | `dist/itch.zip` | [ITCH_GUIDE_RU.md](ITCH_GUIDE_RU.md) | [LISTING.md](LISTING.md#itchio) | `images/itch/` |
| Яндекс Игры | `dist/yandex.zip` (запасной: `dist/yandex-nonet.zip`) | [YANDEX_GUIDE_RU.md](YANDEX_GUIDE_RU.md) | [LISTING.md](LISTING.md#яндекс-игры) | `images/yandex/` |
| CrazyGames | `dist/crazygames.zip` | [CRAZYGAMES_GUIDE_RU.md](CRAZYGAMES_GUIDE_RU.md) | [LISTING.md](LISTING.md#crazygames) | `images/crazygames/` |

`dist/` не хранится в git — архивы собираются командой (секунды, без зависимостей, нужен только Node 18+):

```bash
node tools/build-portals.mjs                 # все три: dist/itch.zip, dist/yandex.zip, dist/crazygames.zip
node tools/build-portals.mjs yandex          # только Яндекс
node tools/build-portals.mjs yandex --no-online   # dist/yandex-nonet.zip — без кнопки «Играть с друзьями»
```

Пересобирайте архивы после любого изменения игры и перед каждой загрузкой новой версии. Отдельный шаг в GitHub Actions не нужен: сборка занимает секунды, а архивы — разовый ручной артефакт; при желании добавьте в workflow шаг `node tools/build-portals.mjs` и `actions/upload-artifact` для `dist/*.zip`.

## Как это устроено

* В архив попадают только файлы, нужные игре во время работы: `index.html`, `styles.css`, `src/`, `vendor/` (библиотеки онлайна), `fonts/`, иконка. Без `sw.js`, манифеста, тестов, документации, Android и десктопа. Размер: ≈1,2 МБ распакованно, ≈0,5 МБ в архиве (лимиты порталов: Яндекс 100 МБ, CrazyGames 250 МБ / начальная загрузка ≤20 МБ, itch 500 МБ).
* Сборщик вписывает в `index.html` флаг `window.VOLAN_PLATFORM` (`itch` / `yandex` / `crazygames`). Всё остальное делает один модуль-адаптер `src/platform/index.js`; остальной код игры вызывает его хуки и про SDK порталов не знает. Обычная веб-версия (GitHub Pages, APK, exe) флага не имеет и работает как раньше.
* Адаптер делает: подключает SDK площадки (с таймаутом: без SDK игра всё равно запускается), определяет язык, сообщает «игра загружена» (`LoadingAPI.ready` / `loadingStop`) и «идёт матч / не идёт» (`GameplayAPI.start/stop` / `gameplayStart/Stop`), принимает паузу площадки (Яндекс `game_api_pause` / `game_api_resume`), решает, показывать ли внешние ссылки, и (CrazyGames) передаёт комнаты и приглашения.
* **Язык.** Исходные тексты игры русские. `src/platform/i18n.js` переводит интерфейс на английский (меню, настройки, профиль, онлайн, подсказки, надписи на корте). Русский — для `ru` и родственных языков СНГ (be, kk, ky, uk, uz, tg, tt, tk, az, hy), английский — для остальных. Яндекс: язык из `ysdk.environment.i18n.lang`; CrazyGames: `user.systemInfo.locale`; itch: язык браузера и переключатель «Русский / English» в настройках. Обычная веб-версия всегда русская.
* **Внешние ссылки.** На Яндексе и CrazyGames в игре нет ни экрана «Скачать» (APK, exe, GitHub), ни ссылки на политику конфиденциальности, ни приглашений со ссылкой на наш сайт. На itch.io всё это остаётся (ссылки открываются в новой вкладке).
* **Service worker** во всех сборках порталов выключен.
* **Онлайн** оставлен во всех сборках и работает внутри iframe портала. Если соединение невозможно, игра честно пишет об этом, а матчи против ИИ остаются полностью играбельными. Приглашения: itch — обычная ссылка; CrazyGames — ссылка из `SDK.game.inviteLink`, `updateRoom`/`leftRoom`, вход по приглашению и `addJoinRoomListener`; Яндекс — только код комнаты (ссылки на страницу игры заранее нет).

## Проверка

```bash
node --test tests/*.test.mjs
python3 tests/browser.py                # обычная веб-версия
python3 tests/portals_browser.py        # собирает и проверяет все три архива с подставными SDK
```

`tests/portals_browser.py` распаковывает каждый архив во временную папку и играет в нём в настоящем Chrome: считает вызовы подставных SDK (ready ровно один раз, start/stop на старте матча, паузе, продолжении и итогах), шлёт `game_api_pause`/`game_api_resume`, проверяет заморозку звука, отсутствие внешних ссылок, service worker и ошибок консоли, играет матч с ИИ на 1366×768 (клавиатура) и 390×844 (касания), проходит английскую версию по всем экранам и ищет остатки русского текста. Снимки экранов — в `tests/screens/portals/` (не в git).

## Риски и что проверить самим

* **Модерация Яндекс Игр и внешние серверы.** Онлайн-режим соединяется с публичными MQTT-брокерами (`broker.emqx.io`, `public.cloud.shiftr.io`, `broker.hivemq.com`, `test.mosquitto.org`, `mqtt.eclipseprojects.io` по WSS) и по WebRTC (PeerJS). В правилах Яндекса (документация на 2026-11-25) про сторонние серверы прямо не сказано — запрещены *ссылки* на внешние ресурсы и скачивание файлов, — но модератор может придраться. Запасной вариант: `dist/yandex-nonet.zip` без онлайна. Подробности — в [руководстве по Яндексу](YANDEX_GUIDE_RU.md).
* **Публичные брокеры нестабильны** и не рассчитаны на продакшен; на портале с большим потоком игроков онлайн может перестать находить комнаты. Против ИИ игра от них не зависит.
* **Правила CrazyGames о мультиплеере**: ники CrazyGames в игре не показываются (рекомендация, не требование Basic Launch); чат отсутствует (только готовые реакции). Решение о Basic/Full Launch принимает их QA.
* **Яндекс**: настоящая проверка SDK возможна только внутри консоли Яндекса (черновик → «Тестировать»); локально проверено на подставном SDK, повторяющем API.
* Игра написана командой ИИ-агентов; если площадка спросит про использование ИИ при создании, отвечайте честно.
