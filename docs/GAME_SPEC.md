# «Волан» — браузерный бадминтон (спецификация для команды агентов)

Цель: лучшая браузерная игра в бадминтон, в которую приятно играть **на телефоне** (портрет и альбом) и на ПК. Без сервера, без сборки: чистый HTML/CSS/JS (ES-модули), публикация через GitHub Pages, устанавливается как веб-приложение (PWA, офлайн).

## Режимы (v1)
- **1×1 против ИИ** и **2×2 (ты + ИИ-напарник против двух ИИ)**.
- Сложность: Новичок / Любитель / Профи / Легенда.
- Быстрый матч и **Турнир** (лестница из 4 соперников с нарастающей силой, прогресс сохраняется в localStorage).
- Тренировка (отработка ударов, подача).

## Правила (официальные, BWF)
- Счёт ралли до 21, разница 2 очка, потолок 30. Матч: до 1 или 3 геймов (настройка, по умолчанию 1 гейм на 21 для быстрого, 3 гейма в турнире).
- Подача снизу, ниже пояса, по диагонали; чётный счёт подающего — правая зона, нечётный — левая.
- Одиночка: узкая боковая линия, длинная задняя. Пара: широкие боковые; при подаче — короткая задняя линия для пар (длинная служебная линия), в розыгрыше — длинная.
- Аут, сетка, двойное касание — очко сопернику. Смена сторон между геймами.

## Физика волана (главное ощущение игры)
- Полу-3D: корт видом сбоку-сверху (2.5D, лёгкая перспектива), волан имеет x (вдоль корта), y (поперёк), z (высота).
- Сильное квадратичное сопротивление воздуха: v' = -g·ẑ - k·|v|·v. Волан резко тормозит после удара → «парашют», почти вертикальное падение после клира. Это узнаваемо и обязательно.
- Волан всегда летит головкой вперёд (визуальный поворот по вектору скорости), тень на полу.
- Высота сетки 1.55 м, корт 13.4 × 6.1 м (одиночный 5.18).

## Удары
Клир (высокий в заднюю зону), дроп (укороченный к сетке), смэш (только если волан высоко и игрок под ним, прыжок), драйв (плоский), подставка у сетки (нет-шот), подъём (лифт). Качество удара зависит от тайминга (раннее/идеальное/позднее касание) и позиции. Идеальный тайминг → вспышка, сильнее и точнее.

## Управление
- **Телефон:** левая половина экрана — виртуальный джойстик (движение). Правая — жесты: тап = автоматический «умный» удар, свайп вверх = клир, свайп вниз = смэш/дроп (смэш если высоко), свайп вперёд коротко = нет-шот/дроп, свайп в сторону = направление. Плюс автопередвижение-помощник (настраиваемо) для новичков.
- **ПК:** WASD/стрелки — движение; J — клир, K — смэш/драйв, L — дроп/сетка, пробел — умный удар/подача. Направление удара — от зажатых клавиш движения.
- Тач-цели крупные, без задержки (pointer events, passive false, нет зума/скролла).

## ИИ
- Позиционирование (возврат в центр корта, «базовая точка»), предсказание точки приземления волана интегрированием физики, выбор удара по ситуации, ошибки по уровню сложности (скорость реакции, точность, частота аутов), стиль игроков (атакующий, защитник, сеточник).
- ИИ-напарник в паре: делёж зоны (атака: спереди-сзади, защита: бок о бок), не мешает игроку, голосовые реплики-иконки.

## Герои (новые, оригинальные)
4–6 персонажей с характерами и статами (скорость, сила, контроль, выносливость): например, Кай Сора (быстрый сеточник), Мира Тан (мощный смэш), Лео Варг (защитник-стена), Айя Рен (хитрые дропы), Тимур Ахмедов (универсал), Нико Блейз (непредсказуемый). Внешность рисуется кодом (canvas), узнаваемые цвета формы и силуэты. Короткие истории в выборе героя.

## Подача и «сок»
Красивый стилизованный корт (дерево/синее покрытие, освещение зала), анимированные игроки (бег, замах, прыжок-смэш, выпад), след волана, частицы, замедление на эффектных смэшах, тряска камеры, звуки ударов (WebAudio, процедурно), толпа, комментатор-подписи («СМЭШ!», «Идеально!»), повтор последнего очка опционально. 60 FPS на среднем телефоне.

## Технически
- Структура: `index.html`, `src/*.js` модули, `manifest.webmanifest`, `sw.js`, `icons/`.
- Фиксированный шаг симуляции (120 Гц), рендер по requestAnimationFrame, devicePixelRatio, ресайз/поворот.
- Язык интерфейса: русский.
- Тест-хуки: `window.__game` с состоянием для автотестов (headless Chrome/Playwright).
