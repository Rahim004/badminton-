# Выкладка «Волана» в Яндекс Игры

Архив: `dist/yandex.zip` (собрать: `node tools/build-portals.mjs yandex`). Запасной архив без онлайна: `dist/yandex-nonet.zip` (`node tools/build-portals.mjs yandex --no-online`). Тексты — [LISTING.md](LISTING.md#яндекс-игры), картинки — `images/yandex/`.

Требования и размеры ниже взяты из документации Яндекс Игр на 2026-11-25 (https://yandex.ru/dev/games/doc/ru/concepts/requirements и «Заполнение черновика»). Точные размеры и лимиты всегда показывает форма черновика в консоли — сверьтесь с ней.

## 1. Регистрация

1. Откройте консоль разработчика Яндекс Игр: https://games.yandex.ru/console/ и войдите с Яндекс ID (заведите отдельный, если не хотите связывать с личным).
2. Создайте профиль разработчика: имя разработчика (отображается игрокам), контактный e-mail (рекомендуется указать — для обратной связи), принятие лицензионного соглашения. Данные для выплат нужны только при подключении рекламы — для публикации без рекламы их можно не заполнять.

## 2. Черновик игры

В консоли: **Добавить игру** → заполнение черновика. Поля и значения:

| Поле | Что указать |
|---|---|

| Версия | можно не указывать (по умолчанию 0.0.0.1) |
| Платформы | **Компьютер** и **Мобильные** (iOS/Android). ТВ не отмечайте — нет управления геймпадом |

| Возрастной рейтинг | заполните анкету честно; для игры без насилия, азарта и чата — обычно **0+** (в онлайне только готовые реакции вроде «Класс!», чата нет) |

| SEO-описание, Краткое описание, Об игре, Как играть | из [LISTING.md](LISTING.md#яндекс-игры) для RU и EN (тексты в разных полях не повторяются — это требование модерации) |

На иконке и обложке нельзя использовать скриншоты игры, рамки, скруглённые углы и элементы интерфейса игры — подготовленные картинки сделаны с учётом этого (портреты героев и логотип).

## 3. Тест перед отправкой

В консоли у черновика есть запуск игры внутри Яндекса. Проверьте на компьютере и телефоне:
1. Игра загрузилась, виден экран главного меню (после него SDK получает `LoadingAPI.ready`).
2. Матч против ИИ: старт, пауза (Esc / кнопка), продолжение, итоги.
3. Переключите вкладку или сверните окно — звук должен умолкнуть, матч встать на паузу.
4. Язык интерфейса соответствует языку аккаунта Яндекса (русский / английский).
5. Нет ссылок наружу: в меню нет «Скачать», в настройках нет политики конфиденциальности.

## 4. Отправка на модерацию

**Опубликовать / Отправить на модерацию.** Срок проверки — от нескольких дней; результат придёт в консоль и на почту. Если игру вернули, исправьте замечание, соберите архив заново и загрузите в тот же черновик.

## Что реализовано под требования Яндекса

| Требование | Как в игре |
|---|---|
| SDK `/sdk.js` + `YaGames.init()` | В `index.html` вписан `<script src="/sdk.js">`; `src/platform/index.js` вызывает `YaGames.init()` с таймаутом 6 с (без SDK игра всё равно запускается) |
| Game Ready (`LoadingAPI.ready`) | Один раз, когда показано главное меню |
| `GameplayAPI.start()/stop()` | `start` — когда идёт матч (старт, продолжение после паузы, онлайн-матч), `stop` — пауза, меню, итоги матча; повторные вызовы отфильтрованы |
| `game_api_pause` / `game_api_resume` | Пауза: матч ставится на паузу, звук замораживается; возобновление: звук возвращается, матч остаётся на паузе до нажатия «Продолжить» |
| Звук умолкает при потере фокуса | События `blur`/`focus` и `visibilitychange` замораживают `AudioContext` |
| Язык через SDK | `ysdk.environment.i18n.lang`: ru и родственные языки СНГ — русский, остальные — английский |
| Без внешних ссылок, скачивания, стороннего входа | Экран «Скачать», ссылки на GitHub/APK/exe и политику скрыты; входа и регистрации нет |
| Реклама только через SDK | Рекламы в игре нет |
| Архив ≤100 МБ, `index.html` в корне, имена без пробелов и кириллицы, относительные пути | Проверяется при каждой сборке |

## Главный риск: онлайн-режим и внешние серверы

Режим «Играть с друзьями» соединяется с публичными MQTT-брокерами по WSS (`broker.emqx.io`, `public.cloud.shiftr.io`, `broker.hivemq.com`, `test.mosquitto.org`, `mqtt.eclipseprojects.io`) и по WebRTC (PeerJS). В правилах Яндекс Игр (на 2026-11-25) нет прямого запрета на обращения к сторонним серверам — запрещены ссылки на внешние ресурсы, скачивание файлов и перенаправления, — но модератор может счесть такие соединения нарушением. В игре нет ничего ссылающегося наружу, а матчи против ИИ полностью работают без сети.

Что делать:
1. Отправляйте `yandex.zip` вместе с комментарием для модераторов (текст готов в LISTING.md).
2. Если вернут с замечанием по сторонним серверам — загрузите `dist/yandex-nonet.zip`: в нём нет кнопки «Играть с друзьями» и сетевой код отключён (остаются матчи 1×1 и 2×2 против ИИ). Для Яндекса можно также снять категорию «Мультиплеер» и убрать упоминания онлайна из текстов.
3. Код комнаты в Яндексе передаётся голосом/в мессенджере: ссылки-приглашения на страницу игры заранее неизвестны, поэтому в лобби есть кнопка «Скопировать код».

## Обновление игры

Соберите новый архив, откройте игру в консоли → **Обновить** → загрузите ZIP в новый черновик; публикация обновления проходит ту же модерацию. Основная концепция игры в новых версиях должна сохраняться.
