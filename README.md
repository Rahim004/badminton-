# Волан — браузерный бадминтон

Бадминтон против ИИ прямо в браузере: одиночка 1×1 и пара 2×2 (ты + ИИ-напарник),
официальные правила BWF, «парашютная» физика волана. Чистый HTML/CSS/JS
(ES-модули), без сборки и зависимостей — работает офлайн и с GitHub Pages
из подпапки (все пути относительные).

## Как запустить

Откройте `index.html` через любой статический сервер (ES-модули не грузятся с `file://`):

```bash
python3 -m http.server 8000
# затем http://localhost:8000/
```

## Как играть

Розыгрыш идёт до падения волана. Очко получает тот, на чьей стороне волан
не упал в пределах корта. Игра до 21 очка с разницей в 2 (максимум 30).

* **Подача** — снизу, по диагонали. При чётном счёте подающего — из правой зоны,
  при нечётном — из левой. Подсвечена зона, куда нужно попасть.
* **Удар** можно нажать заранее: нажатие ждёт в буфере (~0,75 с) и замах
  начнётся сам в нужный кадр. Кольцо вокруг волана сходится к внутреннему —
  в момент совпадения (зелёное) жмите: «Идеально!», удар сильнее и точнее.
  Слишком рано — удар «рано», слабее; волан не долетел — «Мимо!».
* **Смэш** получается, только если волан высоко (над головой); кнопка
  «Смэш/Дроп» при низком волане сыграет укороченный (у сетки — сетку).
* Волан, задевший сетку и упавший на вашей стороне, — очко сопернику.
  Аут — тоже. Линии считаются «в корте».
* **Автобег** (Выкл / Лёгкий / Сильный, по умолчанию на «Новичке» — сильный,
  иначе лёгкий) ведёт игрока к точке перехвата; джойстик всегда главнее —
  при зажатом джойстике автобег лишь слегка подправляет курс.

## Управление

### Телефон (по умолчанию — кнопки)
| Где | Что | Действие |
|---|---|---|
| Левая половина | палец + тянуть | плавающий джойстик (появляется под пальцем) — бег, скорость по отклонению |
| Справа | «Удар» | умный удар (игра выберет сама) / короткая подача |
| Справа | «Клир» | высоко в заднюю зону / длинная подача |
| Справа | «Смэш/Дроп» | смэш, если волан высоко, иначе укороченный |
| Справа | «Сетка» | подставка у сетки / укороченный |

Направление удара — куда отклонён джойстик в момент нажатия (влево/вправо по корту).
Удар срабатывает на касание, бежать и бить можно одновременно.

В паузе → **Управление**: кнопки или свайпы, сила автобега, размер кнопок,
режим для левши (джойстик справа, кнопки слева), вибрация. Сохраняется в
`localStorage['volan.settings'].controls`.

Режим **свайпов**: тап — умный удар (сразу), длинный свайп вверх — клир,
короткий вверх — сетка, вниз — смэш/дроп, вбок — направление.

### Компьютер
| Клавиша | Действие |
|---|---|
| WASD / стрелки | бег |
| Пробел / Shift / Enter | умный удар / короткая подача |
| J или Z | клир / длинная подача |
| K или X | смэш / дроп |
| L или C | сетка / укороченный |
| Esc или P | пауза |

Направление удара задаётся зажатыми клавишами движения (влево/вправо по корту).
Внизу слева — подсказка клавиш.

## Сложность

| Уровень | Что меняется |
|---|---|
| Новичок | медленная реакция, частые ошибки в сетку и аут, промахи |
| Любитель | ошибается заметно реже, начинает атаковать |
| Профи | быстрая реакция, точные удары, мало ошибок |
| Легенда | почти без ошибок, редко «покупается» на обман |

## Тесты

```bash
node --test tests/*.test.mjs        # правила BWF (счёт, зоны подачи, линии, геймы)
node tests/sim.mjs --matches 4      # ИИ против ИИ: длина розыгрышей, доли аутов/сетки
node --test tests/controls.test.mjs # управление: буфер нажатий, автобег, подача
node tests/human_sim.mjs            # эмуляция живого игрока с разбросом тайминга
python3 tests/browser.py            # headless Chrome: портрет/альбом/ПК, тач, клавиатура
python3 tests/controls_browser.py   # живая игра пальцами (CDP multi-touch) и клавиатурой
node --test tests/net.test.mjs       # онлайн: формат, часы, интерполяция, хост↔гость с задержкой/потерями
python3 tests/net_browser.py        # онлайн в двух вкладках (BroadcastChannel, пинг 0/200/300 мс, 2×2, реванш)
python3 tests/net_ui_browser.py     # онлайн с настоящим лобби: ссылка #room-, «Готов», «Начать», реакции, выход хоста
python3 tests/net_real_mq.py        # настоящие MQTT-брокеры (нужен интернет; без него — SKIP)
```

`tests/browser.py` кладёт скриншоты в `tests/screens/`.

## Архитектура (для разработчиков и агентов)

Система координат: метры, `x` — вдоль корта (сетка в 0, задние линии ±6,7),
`y` — поперёк, `z` — высота. Сторона команды — знак `x` её половины.

| Файл | Ответственность |
|---|---|
| `src/config.js` | все константы: корт, физика, удары, тайминг, сложность, герои, форматы |
| `src/physics.js` | полёт волана (`a = −g·ẑ − k·|v|·v`), сетка, приземление, `predictLanding`, `predictTrajectory` |
| `src/shots.js` | типы ударов, солвер начальной скорости под цель, `planShot` |
| `src/rules.js` | правила BWF: счёт, зоны подачи, линии одиночки/пары, геймы, смена сторон |
| `src/player.js` | движение с ускорением, досягаемость, замах, прыжок, выпад, тайминг |
| `src/ai.js` | ИИ: реакция, перехват, решение «аут», выбор удара, формация пары |
| `src/game.js` | оркестратор матча (без DOM, работает и в Node), события |
| `src/render.js` | 2.5D-отрисовка на canvas — можно заменить целиком |
| `src/input.js` | сенсор и клавиатура → абстрактные команды, раскладка кнопок, экран→корт в точке игрока |
| `src/controlsOverlay.js` | джойстик, кнопки ударов, кольцо тайминга, легенда клавиш, вибрация |
| `src/controlsSettings.js` | настройки управления и раздел «Управление» в паузе |
| `src/ui.js` | DOM-экраны: меню, пауза, итоги |
| `src/audio.js` | звук (пока заглушка) |
| `src/main.js` | запуск, цикл (симуляция 120 Гц + rAF), ресайз, `window.__game` |

Модули отображения (`render`, `ui`, `audio`) только читают состояние и подписываются
на события `game.on(...)`: `serveReady`, `serve`, `hit`, `whiff`, `net`, `land`,
`point`, `game`, `sides`, `matchOver`. Публичные функции каждого модуля описаны
в шапке файла — их сигнатуры менять нельзя.

Тест-хуки в браузере: `window.__game.state`, `startMatch({mode, difficulty, format, seed})`,
`step(n)`, `forceAI(true)`, `freeze(true)`, `runUntil(pred)`.

## Онлайн (src/net)

Контракт — `docs/ONLINE_SPEC.md`. Хост-авторитетная модель: хост считает матч, гости шлют ввод
и показывают снимки хоста. Транспорт: ретранслятор через публичные MQTT-брокеры по WSS
(хост слушает комнату на всех сразу, гость закрепляется на первом, где ответил хост), запасной
путь — PeerJS; поверх ретранслятора — прямой канал WebRTC, если получится. Библиотеки лежат в
`vendor/` и грузятся только при выборе онлайна.

| Файл | Ответственность |
|---|---|
| `src/net/index.js` | `createNet(game)`: комнаты, лобби, старт/реванш, переподключение, тексты ошибок |
| `src/net/transport.js` | MQTT/PeerJS/BroadcastChannel, прямой канал WebRTC |
| `src/net/host.js` | ввод гостей по тикам симуляции, снимки 20–30 Гц, события |
| `src/net/guest.js` | показ у гостя: интерполяция, предсказание своего игрока и своего удара, «часы волана» |
| `src/net/codec.js` | компактный формат сообщений и проверка всего, что пришло из сети |
| `src/net/timing.js`, `shuttleline.js` | часы/задержка показа; полёт волана как функция времени |

Как убирается задержка: гость живёт «впереди» хоста ровно настолько, сколько идёт его ввод
(лид подстраивается по отзыву хоста), и предсказывает там своего игрока и полёт волана к себе —
полёт между ударами детерминирован, поэтому гость видит волан там, где он будет, когда его
нажатие дойдёт до хоста. Хост применяет ввод к тому же тику и оценивает тайминг удара так же,
как у локального игрока. Чужие игроки — интерполяция с адаптивной задержкой.
Отладочное лобби без интерфейса: `index.html#netdebug` (`#netdebug-bc` — две вкладки).
