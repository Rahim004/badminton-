# Выкладка «Волана» на CrazyGames

Архив: `dist/crazygames.zip` (собрать: `node tools/build-portals.mjs crazygames`). Тексты — [LISTING.md](LISTING.md#crazygames), картинки — `images/crazygames/`.

Требования взяты из документации CrazyGames на 2026-11-25 (https://docs.crazygames.com/requirements/technical/, …/multiplayer/, …/gameplay/, …/game-covers/ и раздел SDK v3). Названия полей формы в портале разработчика могут отличаться — ориентируйтесь на смысл и на подсказки формы.

## 1. Регистрация

1. Откройте портал разработчиков CrazyGames (https://developer.crazygames.com/ — ссылка с https://docs.crazygames.com) и зарегистрируйтесь: e-mail, пароль, имя студии/разработчика, принятие условий.
2. Для бесплатной загрузки платёжные данные не нужны; они понадобятся, когда игра начнёт приносить доход от рекламы (CrazyGames делит доход с разработчиком).

## 2. Загрузка сборки

1. В портале: **Upload / Add game** → тип HTML5 → загрузите `dist/crazygames.zip`. `index.html` лежит в корне, пути относительные; файлов 53 (лимит 1500), ≈1,2 МБ распакованно (лимит 250 МБ; начальная загрузка ≤20 МБ нужна для показа на мобильной главной — у нас ≈0,5 МБ).
2. SDK v3 подключён в `index.html` (`https://sdk.crazygames.com/crazygames-sdk-v3.js`). Игра вызывает: `init`, `game.loadingStart` / `loadingStop`, `game.gameplayStart` / `gameplayStop`, и для мультиплеера — `game.inviteLink`, `updateRoom`, `leftRoom`, `getInviteParam`, `addJoinRoomListener`, `isInstantMultiplayer`. Вне доменов CrazyGames (SDK в режиме `disabled`) вызовы пропускаются, игра работает как обычно.
3. **Запуск.** Реклама через SDK в игре не подключена, поэтому выбирайте **Basic Launch** («базовый запуск»: SDK необязателен, реклама не показывается; вопрос Basic/Full для мультиплеерных игр решает их QA).

## 4. Что проверяет их команда и как это закрыто

| Требование | Как в игре |
|---|---|
| Относительные пути, ≤250 МБ / ≤1500 файлов, начальная загрузка ≤20 МБ | ≈0,5 МБ в архиве, 53 файла |
| Читаемость при `devicePixelRatio: 1`, 16:9 от 800×450 до 1920×1080 и на телефоне | Проверено на 1366×768 и 390×844; интерфейс масштабируется под вьюпорт |
| Физика одинакова на 60/144/165 Гц | Симуляция идёт фиксированным шагом 120 Гц, отрисовка — по `requestAnimationFrame` |
| Английский обязателен, язык из SDK | `user.systemInfo.locale`; для не-русских и не-СНГ языков — английский интерфейс (полный перевод экранов) |
| Без собственной кнопки полного экрана | В игре её нет |
| Без перекрёстной рекламы и ссылок на магазины | Ссылки на GitHub, APK, exe и политику скрыты |
| `user-select: none` на body, безопасные зоны | Есть в `styles.css` (поля ввода выделяются); `env(safe-area-inset-*)` учтены |
| Пробел и стрелки не прокручивают страницу | В сборке порталов `keydown` для этих клавиш гасится вне полей ввода |
| `gameplayStart` / `gameplayStop` на каждой паузе, меню, итогах | Реализовано; при потере фокуса окна не вызываются (по их правилам) |
| Мультиплеер «Online with Friends»: `updateRoom`, приглашения | `updateRoom({roomId, isJoinable: true, inviteParams})` при создании/входе в комнату, `isJoinable: false` во время матча, `leftRoom()` при выходе; ссылка-приглашение — `game.inviteLink({roomId})`; вход по приглашению при запуске (`getInviteParam('roomId')`) и внутри игры (`addJoinRoomListener`); при `isInstantMultiplayer` игра сразу создаёт приватную комнату (профиль уже есть — без вопросов; иначе сначала короткое создание профиля) |
| Раунды: продолжать с той же группой | После матча — «Реванш» в той же комнате |
| Чат и модерация | Чата нет, только готовые реакции («Класс!», «Огонь!» …) — модерация текста не нужна |
| Ники CrazyGames в игре (рекомендация) | **Не сделано**: игра показывает ник профиля, который игрок задаёт сам |

## 5. Онлайн и приватность

Онлайн-режим соединяет игроков через публичные MQTT-серверы и напрямую по WebRTC (PeerJS); другим игрокам комнаты передаются ник, герой и игровые действия. Это единственное, что покидает устройство; если форма спросит о сторонних сервисах и данных — укажите именно так.

## 6. Тест перед отправкой

В портале запустите сборку в их тестовом режиме (QA Tool / preview): загрузка, матч против ИИ, пауза, итоги, онлайн-комната (в одном окне — создать, во втором — войти по приглашению), мобильная версия. Локально SDK ведёт себя как `local` (на `localhost`): события пишутся в консоль.
